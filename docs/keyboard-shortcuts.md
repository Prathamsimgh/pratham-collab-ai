# Keyboard Shortcuts

Shortcuts available in the Pratham Collab AI editor. All shortcuts work on
Windows and macOS (use `Cmd` instead of `Ctrl` on macOS).

## Text formatting

| Shortcut | Action |
| -------- | ------ |
| `Ctrl` + `B` | Bold selected text |
| `Ctrl` + `I` | Italicise selected text |
| `Ctrl` + `U` | Underline selected text |
| `Ctrl` + `Shift` + `X` | Strikethrough selected text |
| `` Ctrl + ` `` | Inline code |

## Editing

| Shortcut | Action |
| -------- | ------ |
| `Ctrl` + `Z` | Undo |
| `Ctrl` + `Shift` + `Z` / `Ctrl` + `Y` | Redo |
| `Ctrl` + `A` | Select all text in the document |
| `Ctrl` + `K` | Insert or edit a link |
| `Ctrl` + `/` | Toggle the AI toolbar |

## Headings and lists

| Shortcut | Action |
| -------- | ------ |
| `Ctrl` + `Alt` + `1` | Heading 1 |
| `Ctrl` + `Alt` + `2` | Heading 2 |
| `Ctrl` + `Alt` + `3` | Heading 3 |
| `Ctrl` + `Shift` + `8` | Bullet list |
| `Ctrl` + `Shift` + `9` | Numbered list |

## Collaboration

| Shortcut | Action |
| -------- | ------ |
| `Ctrl` + `S` | Save the document (auto-save is on by default) |
| `Ctrl` + `Shift` + `C` | Copy the share link for the document |
| `Ctrl` + `Shift` + `P` | Open the document preview |

> Tip: shortcuts are handled by the editor, so they only work while the
> editor has focus. Click into the document first if a shortcut does not
> seem to respond.
